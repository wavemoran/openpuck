Before you start

What is OpenPuck? Free, open-source software for the Life Puck: life totals for one or two players, a game timer, history, colors and a battery indicator.

Read the user guide View on GitHub

Unofficial software. Use at your own risk.

  • OpenPuck is an independent, unofficial project. It is not made, supported or endorsed by the maker of the Life Puck, and they can't help you with it.
  • Installing replaces the software on your puck. If something goes wrong, the puck can stop working (“bricked”). The backup and the restore page can usually bring it back, but there is no guarantee.
  • It may void your warranty.
  • OpenPuck is provided as is, without warranty of any kind (Apache License 2.0).

What you need

  • A charged puck
  • A USB-C cable that carries data (some cables only charge)
  • A computer. It takes about 2 minutes.

The installer first saves a backup of your puck and won't continue until you have saved it. Keep that file private: it contains the original software, so don't share it or post it online. Don't unplug the puck while it is being written.
