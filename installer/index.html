Install OpenPuck

Before you start

This puts OpenPuck on your Life Puck. It will back up the puck, then install OpenPuck. It takes about 2 minutes.

What you need

  • A charged puck
  • A USB-C cable that carries data (some cables only charge)
  • A computer

Please read

  • Installing is at your own risk. It may affect your warranty.
  • The backup is the only way back to the original software. The installer won't continue until you have saved it.
  • Keep your backup file private. It contains the original software, so don't share it or post it online.
  • Don't unplug the puck while it is being written.
